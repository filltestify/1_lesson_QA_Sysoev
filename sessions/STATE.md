## Известные проблемы

Статус на конец сессии 6 (подробности и доказательства —
`bug-reports.md`):
1. **Закрыт.** XSS/HTML-инъекция через поле «Имя»/«Адрес»/«Телефон»/
   «Комментарий» — исправлено экранированием, перепроверено живьём.
2. **Открыт частично.** Испорченный `localStorage["orders"]`: невалидный
   JSON теперь обрабатывается корректно; валидный массив с заказом без
   поля `items` — всё ещё роняет экран «Мои заказы» тем же исключением.
3. **Открыт, без изменений.** Отправка формы оформления при опустошённой
   корзине молча возвращает на экран меню без сообщения — не входил в
   заявленные фиксы, регрессии тоже нет.
4. **Закрыт.** Данные формы оформления теперь очищаются после успешного
   заказа — перепроверено живьём, старые данные больше не подставляются.
5. **Открыт.** Тексты ошибок валидации остаются на экране между визитами
   без новой попытки отправки — заявленный фикс («тексты ошибок...
   сбрасываются») сбрасывает их только на успешном пути отправки, этот
   сценарий успеха не требует и потому не покрыт.

Дополнительно зафиксированы (не баги, открытые вопросы без решения):
корзина не переживает перезагрузку страницы; повторная отправка формы
может создать дублирующий заказ; слоты доставки не учитывают часы
работы заведения; пробелы по краям имени/адреса не обрабатываются
отдельно.
