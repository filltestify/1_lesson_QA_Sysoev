## Известные проблемы

Пять подтверждённых багов (подробности и доказательства —
`bug-reports.md`):
1. **Критично.** XSS/HTML-инъекция через поле «Имя» (и вероятно
   «Адрес»/«Телефон»/«Комментарий») на экране подтверждения заказа.
2. **Критично.** Некорректные данные в `localStorage["orders"]`
   (невалидный JSON, отсутствие поля `items`, либо не-массив) роняют
   переход на экран «Мои заказы» необработанным исключением.
3. **Не критично.** Отправка формы оформления при опустошённой корзине
   молча возвращает на экран меню без сообщения.
4. **Критично.** Данные формы оформления (имя/адрес/телефон/
   комментарий) не очищаются между визитами на экран — риск отправить
   новый заказ со старыми чужими данными (подтверждено дважды на
   практике при тестировании).
5. **Не критично.** Тексты ошибок валидации остаются на экране между
   визитами без новой попытки отправки — косметика.

Дополнительно зафиксированы (не баги, открытые вопросы без решения):
корзина не переживает перезагрузку страницы; повторная отправка формы
может создать дублирующий заказ; слоты доставки не учитывают часы
работы заведения; пробелы по краям имени/адреса не обрабатываются
отдельно.
